# Сайт Заречной общины

Статический сайт без CMS, базы данных, внешних шрифтов и сторонних скриптов. Открывается через `index.html` и работает на обычном бесплатном хостинге. Изображения взяты из предоставленного архитектурного проекта; это визуализации, не фотографии стройки.

## Обновление

Просите Codex внести изменения в этой папке. Подготовьте дату отчёта, выполненные работы, планы и реальные фотографии. Основные меняющиеся данные находятся в `content.js`, постоянные тексты — в `index.html`. Не нужно устанавливать Node.js или компилировать сайт.

В `content.js` заполните подтверждённые `currentStage`, `updatedAt`, `nextStage`, `phone`, `email`, `contactPerson`, `donationText`, `scheduleText`. Добавляйте записи в `reports` и фотографии в `constructionPhotos` по примерам в начале файла. Даты — YYYY-MM-DD, пути фотографий — assets/building/имя.webp (латиницей). Новые отчёты автоматически появляются первыми. Нет введённых реквизитов — нет платёжной кнопки. Форм отправки и сбора данных в этой версии нет. Контакты включаются только после заполнения.

## Основное размещение: GitHub Pages

Локальный Git-репозиторий содержит исходники и публичные файлы сайта. Временные скриншоты, ZIP-архив и прежняя папка `статический на beget` исключены через `.gitignore`. `.nojekyll` отключает обработку сайта Jekyll.

1. В аккаунте GitHub создать **пустой публичный** репозиторий `rpsc-nnov`. При создании не добавлять README, .gitignore или лицензию: локальный репозиторий уже содержит первый коммит.
2. Подключить URL созданного репозитория: `git remote add origin https://github.com/ВАШ-ЛОГИН/rpsc-nnov.git`.
3. Выполнить `git push -u origin main`. Если GitHub запросит вход, использовать вход через браузер или менеджер учётных данных; пароль аккаунта не вставлять в команду.
4. В репозитории GitHub: Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.
5. Проверить временный адрес https://ВАШ-ЛОГИН.github.io/rpsc-nnov/. Затем добавить `rpsc-nnov.ru` в Custom domain и настроить DNS по актуальной документации GitHub. Добавленный GitHub файл CNAME получить локально командой `git pull --ff-only` перед следующими изменениями.

Обычное обновление: получить изменения `git pull --ff-only`, отредактировать сайт локально, проверить `git diff`, выполнить `git add` для изменённых файлов, `git commit -m "Описание изменения"`, затем `git push`. `git fetch origin` только получает сведения об удалённых изменениях; он не отправляет локальные коммиты и не меняет рабочие файлы.

Репозиторий публичен, поэтому в него нельзя добавлять пароли или приватные сведения. Жёлтые заглушки и полный архитектурный PDF сейчас входят в сайт и будут доступны посетителям при публикации. Перед внешней публикацией проверить состав материалов.

## Альтернативное размещение на бесплатном Beget

1. Создать аккаунт бесплатного хостинга и добавить rpsc-nnov.ru в панели. Проверить действующие ограничения и возможность бесплатного HTTPS для своего домена.
2. Сделать резервную копию существующих файлов сайта и сохранить текущие DNS-записи, в том числе почтовые.
3. Загрузить **содержимое** архива `site-upload.zip` в корневую публичную папку сайта (`public_html` или папку, указанную в панели), не сам архив. Файл `index.html` должен лежать непосредственно в ней. Не загружать `tmp`, README и инструменты проверки.
4. Получить параметры DNS в панели Beget. Направить домен на хостинг; не копировать IP-адрес из посторонних инструкций. Подключить www при необходимости, проверить обе версии адреса.
5. Настроить HTTPS и проверить сайт с телефона. Только после успешного подключения HTTPS включать перенаправление HTTP → HTTPS средствами панели.

Размещение ещё не выполнено: нужны аккаунт хостинга и управление доменом. Исходный PDF включён в публичные файлы как архитектурный проект; перед публикацией проверьте, что община согласна публиковать полный комплект. Он занимает около 10,5 МБ.

## Проверка и упаковка

`python tools/check_site.py` проверяет локальные ссылки и формирует `site-upload.zip` только из публичных файлов. Для предпросмотра: `python -m http.server 8080 --bind 127.0.0.1`, затем открыть http://127.0.0.1:8080. Python для работы самого сайта не нужен.

Сайт намеренно не содержит вымышленных отчётов, фотографий стройки, точного номера дома, расписания, реквизитов или контактных лиц. По просьбе пользователя недостающие данные выделены яркими жёлтыми заглушками. Заглушки автоматически исчезают после заполнения соответствующих полей в content.js. Контактное лицо можно указать рядом с телефоном в HTML или расширить данные при следующем обновлении.
